ADB Studio —— 网页版 ADB 工具

在浏览器里直接使用 ADB：通过 WebUSB 连上安卓设备，不需要安装 adb，也不需要装任何客户端。ADB 协议由页面自己实现，所以打开网址就能开始用。

能做什么

  • 设备信息：型号、安卓版本、序列号、连接方式、root 状态。
  • 应用管理：浏览已安装应用及真实图标、拖拽安装 APK、卸载。
  • 文件传输：把文件拖到页面上就推到设备里。
  • 投屏：基于 scrcpy，H.264 / H.265 由 WebCodecs 硬解码，支持鼠标键盘触控。
  • 实时日志：logcat 按进程和级别过滤。
  • 抓包：实时查看应用的 HTTP / gRPC / WebSocket 流量，而且是应用层明文（HTTPS 加密前 / 解密后），不需要 MITM 代理、不需要安装证书、不受 certificate pinning 影响。gRPC 能看到 method、metadata、流式消息和 status，protobuf 显示真实字段名。 需要目标应用集成 netcapture SDK。

浏览器要求

需要支持 WebUSB 的浏览器：Chrome 或 Edge，并且页面必须通过 HTTPS 打开。Safari 和 Firefox 目前不支持 WebUSB。本机已经在跑 adb（比如开着 Android Studio）时 USB 接口会被它独占，页面里提供了一个小桥接程序让两者共用同一台设备。
